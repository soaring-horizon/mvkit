# 双目重建与二维三维联动

视差过滤 → 双目重建 / 校正左图分割 → 区域提取点云 → 三维测量

1. 点击“连续运行”，两组输入分别约为 2 m、1 m 平面。
2. 选择双目重建，在输出下拉框查看左右校正图、视差、质量、XYZ 与有效点。
3. 在点云选取节点的校正左图/深度图画 ROI，或调整分割阈值观察区域 B 选点。
4. 在视差过滤中调整代价和连通面积。
5. 数据菜单可导出点云；迁移工程时在“另存工程”勾选复制原始数据。

两组自建解析输入，三维点与测量为 mm，XYZ 图为 m。已有冻结双目标定，无需训练。深度范围不是相对平面的高度；这是算法入门示例，不是实际设备标定。
