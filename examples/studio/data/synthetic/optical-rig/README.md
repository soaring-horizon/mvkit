# 机加工件重建数据

这组数据由 MVKit 的开发工具 `mvkit_prepare_release_samples` 生成。虚拟相机采用 640 × 480 图像、1000 px 焦距和 30 mm 基线。双目左右图分别从两台虚拟相机渲染。结构光图案由 MVKit SDK 生成，按计算出的投影坐标产生 25 帧有序曝光。

工件的几何由底座、凸台、孔和加强筋的可见表面构成。渲染包含表面纹理、非均匀照明、暗角、投影遮挡和固定种子的传感器噪声。工件采用分层表面近似，镜头使用零畸变基准。可用这组数据验证投影几何、遮挡与解码流程，真实金属多次反射和镜头畸变由开发实拍版补充覆盖。

| 文件 | 值与坐标 |
|---|---|
| `truth.json` | 相机参数、右相机与投影仪相对于左相机的位姿、工件名义深度和曝光信息 |
| `part/depth-0.1mm.png` | 左相机光轴方向的 Z，16 位灰度，像素整数值乘 0.1 得到 mm |
| `part/projector-column-1over64px.png`、`part/projector-row-1over64px.png` | 投影列、行坐标，16 位灰度，整数值除以 64 得到 px。65535 表示坐标越界。坐标本身不编码遮挡 |
| `part/foreground.png` | 工件前景为 255，背景为 0 |
| `verification.json` | MVKit 运行后的有效点数、前景深度绝对误差中位数 |

重建工作流读取图像和虚拟设备参数。真值栅格可用于比较重建结果。
